# The Glossary

A small, dependency-free personal reference app for **theglossary.online**.

## Design
- Oak, parchment, light forest green, walnut, and brass palette
- Term buttons act like a library index
- Clicking a term reveals its definition, examples, history, comparison, or diagram
- Search and category filtering
- Responsive mobile layout
- No framework, build step, database, or login

## Files
- `index.html` — shell and accessible layout
- `styles.css` — oak / forest-green library styling
- `app.js` — glossary data and interaction
- `netlify.toml` — static Netlify configuration

## Deploy
This branch can be deployed as a plain static site. Publish directory: repository root (`.`). No build command is required.

Target domain: **theglossary.online**
